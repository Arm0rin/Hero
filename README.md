# HERO — первый этап

Отдельный Unity 6 проект для портретной мобильной игры; не относится к TelePlay.

## Открыть

1. Добавить эту папку в Unity Hub и открыть в Unity 6.0 (ориентир 6000.0.23f1) с установленным модулем WebGL Build Support.
2. Если Package Manager предлагает обновить пакеты, сначала убедиться, что версия совместима с выбранным редактором.
3. Запустить меню **HERO → Build First Milestone Scenes**. Команда создаст 00_Boot (заготовку), 90_Dev_Playground, конфиг движения и добавит playground в Build Settings.
4. Открыть `Assets/_Game/Scenes/90_Dev_Playground.unity` и нажать Play. В редакторе: WASD, пробел, правая кнопка мыши для камеры. На телефоне: джойстик, Jump, свайп справа.
5. В Player Settings выбрать портретную ориентацию и активировать Legacy Input Manager либо Both (код использует `UnityEngine.Input`). Переключить Build Target на WebGL и собрать тест. Настроить WebGL шаблон и Telegram отдельно после успешного локального билда.

## Статус

Созданы код контроллера (ускорение, воздушное управление, прыжок, coyote time, jump buffer), виртуальный джойстик, кнопка прыжка, камера с поворотом и SphereCast, генератор тестового уровня. Tower, сохранения, герой-хаб, Telegram и backend ещё не реализованы. `00_Boot` только заготовка. Unity Editor в среде подготовки не установлен, поэтому компиляция, WebGL билд и проверка на телефоне пока не подтверждены. Gate 0 и Gate 1 открыты.

## Замечания для первой проверки

Подобрать значения `PlayerMovement.asset` после реального теста на iPhone и Android. Проверить ориентацию, safe area, столкновения камеры, управление при перехвате касаний и стабильность WebGL в Telegram. Затем зафиксировать рабочий Unity-проект в Git и перейти к следующему этапу только после прохождения gate.
